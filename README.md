# Kokpit Cep

Kokpit zaman takibinin telefon uygulamasi. Telefonda acip **Ana ekrana ekle** ile kurulur; internetsiz calisir,
kayitlar telefonda kalir ve masaustu Kokpit ile dosyayla esitlenir.

Bu depo Kokpit masaustu projesindeki `mobile/` klasorunden `scripts/cep-yayinla.ps1` ile uretilir; dogrudan duzenlenmez.
